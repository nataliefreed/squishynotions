Shortcuts and tips

Move and select

Drag
Move an item. Items snap to the page and to each other.
Shift drag
Keep the move in one direction
Ctrl drag
Hold while dragging to skip snapping
Shift click
Add or remove an item from the selection
Drag a box
Select everything the box touches
Arrow keys
Nudge a little (Shift = a lot)
CtrlA
Select all

Copy and arrange

Alt drag
Drag a copy and leave the original behind
CtrlD
Duplicate
CtrlC CtrlV
Copy and paste
Delete
Remove the selection
CtrlZ
Undo (add Shift to redo)

Resize and rotate

Corner handles
Resize one item or a whole group. On text this changes the font size.
Round handle
Rotate one item or a whole group. Shift = 15° steps.

Print

File → Print
Prints just the page, at the paper size you picked. Use PDF in the download menu if printing is blocked.

Text

Double-click
Edit a text box (or press Enter)
Esc
Finish editing
