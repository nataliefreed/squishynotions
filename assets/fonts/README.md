# Fonts

The site's two fonts came with the old WordPress theme. Put these seven files in this folder
(`assets/css/style.css` already points at them), then delete this README:

- `DMMono-Light.ttf`
- `DMMono-LightItalic.ttf`
- `DMMono-Regular.ttf`
- `DMMono-Italic.ttf`
- `DMMono-Medium.ttf`
- `DMMono-MediumItalic.ttf`
- `uni05_53.ttf`

On the old site they were at `https://www.squishynotions.com/wp-content/themes/pixl/assets/fonts/`.

Until they're here, browsers use their own monospace font instead (for the site title too), so the
layout holds together but it won't look quite like the old site.

DM Mono is also free on Google Fonts, under the SIL Open Font License, if you'd rather download it
from there. "uni 05_53" is a small pixel font; check that its license allows putting it on a
website before you publish it.
