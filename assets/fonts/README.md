# Fonts

The site's two fonts come from the old WordPress theme. Put these seven files in this folder
(`assets/css/fonts.css` already points at them), then delete this README:

- `DMMono-Light.ttf`
- `DMMono-LightItalic.ttf`
- `DMMono-Regular.ttf`
- `DMMono-Italic.ttf`
- `DMMono-Medium.ttf`
- `DMMono-MediumItalic.ttf`
- `uni05_53.ttf`

On the old site they were at `https://www.squishynotions.com/wp-content/themes/pixl/assets/fonts/`.
Until they're here, the browser falls back to a generic sans-serif font.
